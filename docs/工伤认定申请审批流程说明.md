# 工伤认定申请审批流程说明

## 1. 核心规则

- 一个安全生产事故对应一个审批流程。
- 一个事故可以包含多张工伤认定申请表，所有申请表统一随事故提交审批。
- 没有工伤认定申请表的事故不进入审批流程。
- 主管部门负责人为并行抄送节点，不影响主流程流转。

## 2. 流程节点

```text
发起单位提交
    ↓
安全环保部审批
    ├─→ 主管部门负责人抄送（并行、非阻塞）
    ↓
人力资源部部长审批
    ↓ 选择工伤保险办理人员
工伤保险办理人员签收
    ↓
结束
```

## 3. 页面交互

### 事故记录列表

“工伤申请”状态显示四种状态：

- 无工伤申请
- 待发起审批
- 审批中
- 已结束

没有申请表时显示“无工伤申请”，不提供流程操作。

### 事故详情页

- 所有申请表填写完成后，页面右上角显示“发起审批”。
- 流程发起后，右上角显示当前节点的“审批”按钮。
- 点击审批后打开审批弹窗，确认提交时需要二次确认。
- 人力资源部部长审批时，必须选择工伤保险办理人员。
- 审批完成后进入下一节点，签收完成后流程结束。

## 4. 关键数据字段

```js
workflowStatus     // 未发起、审批中、已结束
currentNode        // 当前办理节点
ccStatus           // 主管部门抄送状态
hrStatus           // 人力资源部审批状态
insuranceHandler   // 工伤保险办理人员
```

当前原型使用 Mock 数据实现，不调用后台接口。正式开发时需将流程状态、办理人和审批记录改为后端数据，并按权限返回可操作节点。
